# Bem vindo 👋

Trabalho feito para a materia Programação Para Dispositivos Móveis em Android. nele voce podera acessar o projeto pelo navegador web, mobile (Android, Ios).
a ideia é visualizar o tempo da regiao(estado) de forma facilitada.

O projeto em si, mostra o clima, Sensação termica, Umidade e o vento do dia atual e dos proximos dias.

Api usada é da OpenWeathermap.

## Instalação do projeto

1. Instalação de dependências

   ```bash
   npm install
   ```

2. Iniciar o app

   ```bash
   npx expo start
   ```
